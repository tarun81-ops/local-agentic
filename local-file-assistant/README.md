# Local File Assistant

Ask natural-language questions about your local files (PDF, docx, pptx, xlsx, images, notes)
and get answers with exact file + page citations. 100% local: nothing leaves the machine.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/ROADMAP.md](docs/ROADMAP.md).

## Dev setup (Windows 11, PowerShell)

```powershell
scripts\setup.ps1
scripts\start-dev.ps1
```
